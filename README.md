# Michelle Birkkjær Nielsen · Portfolio

Upload everything in this folder to the root of the GitHub Pages repository (including the hidden `.nojekyll` file).

## Files
- `index.html` — the whole site
- `support.js` — runtime the page needs
- `image-slot.js` + `image-slots.state.json` — the case study images (keep them together, next to index.html)
- `dibu-laptop-bg.png`, `dibu-minside-scroll.webp`, `dibu-minprofil-scroll.webp` — DiBU 2.0 scrolling laptops
- `surr-laptop.png`, `surr-landing-scroll.webp`, `surr-program-scroll.webp` — Surround Festival scrolling laptops
- `Michelle-Birkkjaer-Nielsen-CV.pdf` — behind the Download CV button
- `favicon.png` — browser tab icon
- `.nojekyll` — tells GitHub Pages to serve the files as-is

## Where to edit things (script at the bottom of index.html)
- `CV_URL` — CV file name. Empty hides the Download CV button.
- `PROJECTS` — case order, titles and card text.
- `CASE_SLOTS` — image order per case; the first filled one is used as the carousel thumbnail.
